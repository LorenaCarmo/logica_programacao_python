# Python | Exercícios e Prática

Repositório dedicado à prática de exercícios de programação em Python, com foco no desenvolvimento da lógica de programação, raciocínio computacional e consolidação dos fundamentos da linguagem.

## Objetivos

- Praticar lógica de programação e algoritmos.
- Consolidar os fundamentos da linguagem Python.
- Desenvolver o raciocínio lógico e a capacidade de resolução de problemas.
- Aplicar os conceitos estudados por meio de exercícios práticos.
- Registrar a evolução e acompanhar o aprendizado.

## Conteúdos praticados

- Variáveis e tipos de dados.
- Identificadores e palavras reservadas.
- Operadores aritméticos, relacionais e lógicos.
- Estruturas condicionais (`if`, `elif`, `else`).
- Estruturas de repetição (`for`, `while`).
- Funções, parâmetros e argumentos.
- Estruturas de dados e listas.
- Algoritmos e resolução de problemas.

## Tecnologias e ferramentas

- Python
- Visual Studio Code
- Git e GitHub

## Organização do repositório

Os exercícios são organizados por assunto e/ou conteúdo estudado, facilitando a consulta, a revisão e o acompanhamento da evolução.

## Status

Em desenvolvimento contínuo, acompanhando o progresso dos estudos de Python e lógica de programação.
